# Lessons 压缩版 v6

## 长期原则

- 用户视角验收：未验证 = 未完成。
- 空值优于假数据。
- 第二个同接口实现时抽象。
- v1 后先安全与债务硬化。
- Provider 名称不等于真实后端。
- API 测试分 smoke/functional/stress，并显式控制成本。

## 最近两个月

- 应用接纳高于命令成功。
- 结论强度匹配证据强度。
- 浏览器状态是版本化数据库。
- 交互系统需要状态/语义/内容不变量。
- 测试结论匹配测试深度并绑定 SHA。
- 排他性最小需求是合同。
- 真实阅读时长按 active state 计量。
- 工程图纸参数先确定 reference plane。
- 修改现有作品采用保护式变换和负向 diff。
- 复杂提示词是可执行规格。
- **事实源知识必须在维护中存活；压缩只属于派生/Compact 层。**

## 写作与多智能体

材料账本 + 命题表 + 冲突/反证 + 引用审计；Agent 共用事实 Schema，最终统一裁决。
