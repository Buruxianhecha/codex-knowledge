# Lessons 压缩版 v5

## 长期原则

- 用户视角验收：未验证 = 未完成；已有多项目/三个月证据，best_practice。
- 空值优于假数据；第二个实现时抽象；v1 后先硬化。
- Provider 名称不等于真实后端；测试声明必须匹配深度和 SHA。

## 最近两个月

- 应用接纳高于命令成功。
- 结论强度匹配证据强度。
- 浏览器状态是版本化数据库。
- 交互系统需要状态/语义/内容不变量。
- 排他性最小需求是合同。
- 行为时长按 active state。
- 现有作品修改是约束式变换并做负向 diff。
- 图纸输入先确定 reference plane。
- 复杂提示词是可执行规格；复杂任务适合时多智能体共享 Schema。
