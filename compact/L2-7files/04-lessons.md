# Lessons 压缩版 v4

## 长期原则

- 用户视角验收：未验证 = 未完成。
- 空值优于假数据。
- 第二个实现时抽象。
- v1 后先安全与债务硬化。
- 多引擎按质量择优，输出前质量门控。
- Provider 名称不等于真实后端。
- API smoke/functional/stress 分级并控制成本。

## 2026-06-26 至 08-26 新经验

- 应用接纳高于命令成功；动态环境实例修好不等于客户端接受。
- 结论强度匹配证据强度；盘中、收盘和最终值分开。
- 浏览器状态是版本化数据库，不是可随意清空的缓存。
- 交互系统需要状态、语义和内容三类不变量。
- 测试结论匹配测试深度并绑定 SHA。
- 排他性最小需求是合同，额外功能可能就是缺陷。
- 写作先建材料账本和命题表，再写叙事。
- 多智能体研究按证据职责拆分，由统一引用审计收口。
