# Core Knowledge 压缩版 v6

## 最高优先级

未验证 = 未完成；用户实际优先；结论不超过证据；排他需求是合同；保护式修改；行为时间按有效状态；浏览器状态按数据库；敏感信息不入公开库；事实源不为维护压成摘要。

## 生命周期

Lesson 2+ 独立证据；Pattern 2+ 独立成功项目；Best practice 3+ 成功应用 + 3 个月稳定 + 可执行验收。多引擎/SQLite migration/质量门控保持 active；06-22 绝对路径模式已 superseded。

## 近期工程

- 卡塞尔/剑来/凡人：状态机、单调存档、动作语义、VM/smoke/CI；测试深度分开。
- 拾光：IndexedDB + owner 隔离 + Auth Provider；仍是测试版。
- 文章货架：`route && visible && focused && !idle && session` 才累计；chunk 幂等、多标签防双算。
- BIM：reference plane -> size -> offset -> local addition -> scope -> 3D/断面。
- 约束式编辑：Must change / Must preserve / May adapt + 负向 diff。

## Windows / Auth 修正

- PowerShell 5.1 与 7+ 编码默认不同；BOM 不是跨版本万能答案。
- `.NET String` 的 UTF-16 内部表示不是乱码天然根因。
- Device Code 使用自己的 public-client app registration；token 轮询必须带同一 `client_id`。

## 写作研究

材料账本 + 命题表 + 正反证据 + 允许措辞/禁止升级 + 引用审计；多智能体按证据职责拆分，共享 Schema 后统一裁决。

## 自动审计

`validate_knowledge.py` 管结构/生命周期/隐私；`check_source_regression.py` 防事实源大幅缩水。Legacy registry 是显式兼容层，不通过删正文来清债务。
