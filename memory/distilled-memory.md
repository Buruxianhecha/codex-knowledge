## 最高优先级原则

- 未验证 = 未完成；完成层级分开报告。
- 用户实际优先于理论推断。
- 排他需求是合同；修改现有作品保护未指定区域。
- 结论强度不超过证据强度。
- 行为时间按 active state，而不是页面墙钟时间计量。
- 浏览器长期状态按数据库处理，不靠清空迁移。
- 敏感凭据和具体本机用户名路径不进公开知识库。
- Pattern 至少两个独立成功项目才可 `verified`。
