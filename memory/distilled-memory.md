## 最高优先级原则

| 原则 | 含义 |
|------|------|
| 未验证 = 未完成 | 命令、构建、上传、宿主接纳和用户路径分层报告 |
| 用户实际优先 | 理论结果与用户体验冲突时继续复现和排查 |
| 排他需求是合同 | “只/仅/不要/单文件”禁止善意扩展 |
| 修改现有作品先保护 | 未点名模板、布局、数据、功能默认保持 |
| 结论不超过证据 | 参与不写主导，盘中不写收盘，手册不写部署成功 |
| 行为时间按有效状态计量 | 页面打开不等于阅读/学习/工作 |
| 空值优于假数据 | 无法确认就留空或标注未确认 |
| 数据不靠清空迁移 | 保留旧档、owner、完成态和恢复路径 |
| 敏感信息不入库 | Key、token、cookie、登录态、AppSecret 默认脱敏 |

## 近期可复用经验

| 经验 | 一句话 |
|------|--------|
| 应用接纳高于命令成功 | 子步骤成功不能替最终拥有者验收 |
| 证据决定措辞 | 动词、范围、时间和最终性都需要对应证据 |
| 浏览器状态是数据库 | 有 schema、owner、revision、迁移、恢复和完成态 |
| 行为时间测 active state | 路由/可见/焦点/idle/Session 共同门控 |
| 单调状态防倒退 | scene/action 版本拒绝重复点击和旧标签页 |
| 动作语义高于位置 | 结果读动作与上下文，不按第几个按钮套公式 |
| 内容变化需语义指纹 | 去掉编号后再比较标题、正文和选项 |
| 测试深度要明说 | smoke、行为、压力、构建、CI 和用户验收不可混称 |
| 最小需求是排他合同 | 明确不需要的功能不能默认加入 |
| 修改现有作品做负向 diff | 既验证该改的，也验证未指定部分没变 |
| 图纸输入先确定基准 | reference/offset/size/local addition 分层，不凭经验补数 |
| 本地测试版不等于云产品 | IndexedDB/Mock 不能冒充备份、授权和真实认证 |
| CI 属于具体 SHA | 旧失败和当前 HEAD 成功可以同时为真 |

## 近期模式

### Auth Provider 模式边界

UI 固定调用 AuthService，由 `AUTH_MODE` 选择 Mock/Real Provider。外部身份映射到内部 `userId`；真实 OAuth 的 secret/token 只在服务端。

### 单调存档事务

读取更晚快照 -> 拒绝旧页面 -> 纯转换 -> 拒绝倒退 -> 同步持久化 -> 更新 UI。

### Activity-Gated Time Accounting

先计算 `active = contextValid && visible && focused && !idle && sessionValid`，只结算 active 区间。chunk 幂等、多标签页防双算、睡眠后长 delta clamp、明确业务时区。

### 多智能体共享 Schema

按依赖图拆分，独立任务并行；所有 Agent 返回统一的事实、证据、冲突、修改建议和未解决项，最终由单一审计角色收口，而不是直接拼接 prose。

### 单文件 VM 测试壳

从 HTML 提取内联脚本，在 Node `vm` 中注入最小 DOM/localStorage 和可控随机数，测试真实状态逻辑；不能替代视觉和真机浏览器验收。

### 材料账本 + 命题表

材料记录 ID、来源层级、日期、定位、SHA-256；命题记录支持/反证、允许措辞和禁止升级措辞。多智能体共用同一账本。

## 近期真实错误

| 错误 | 根因 | 预防 |
|------|------|------|
| 豆包脚本成功但客户端未接纳 | 验证层级过早停止 | 验证宿主、功能和重启保持 |
| 李跳跳文件无导入证明 | 对截断 JSON 做字符串层修复 | 严格解析 + golden sample + 真实导入 |
| 凡人中间红 CI | 相互依赖文件分批 push | 首次 push 前形成完整快照，报告绑定 SHA |
| 电视时钟需求漂移 | 用产品扩展覆盖排他要求 | 建负向清单，回读 DOM 和文件树 |
| 拾光测试站被说成正式上线 | 混淆 preview 与 production | 结论服从最新、最完整验收报告 |

1. 冻结需求和禁止项。
