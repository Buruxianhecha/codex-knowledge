# 怀民亦未寝 0.37.26（62048）· 扩展消息回应

基于用户已真机测试的 0.37.25（62047），独立开发分支，不改变应用包名，不改变 Room 22 数据库版本，不覆盖或删除旧聊天。

## 本次实际实现
- 长按成功的 TA 消息，保留六个快捷 Emoji；通过 + 展开六列表情面板，可以滚动选择。
- 通过 MessageReactions.ALL 白名单让新增 Emoji 真正通过 ReactionEvents 校验、持久化、取消及 AI 感知。修复早期版本“显示但点击无效”的隐蔽故障。
- 持久化最近使用的 Emoji（本机轻量 UI 偏好，最多 8 个），重启后仍可快捷选择。
- 每种 Emoji 聚合成一个玻璃胶囊，显示最多 3 位真实回应者头像和多余人数；点击查看所有回应者，可撤销自己的回应。
- 保留原有表情事件、即时回答、完整聊天备份和群聊消息操作逻辑，版本升级到 0.37.26 / 62048。

- 群聊角色可以通过严格格式的 AI 输出选择对最近一条他人真实消息贴表情，数据库存储真实角色 ID。保留每位角色的独立回应，多位角色使用同一 Emoji 自动聚合。其他普通文字不被当成表情动作。
- 原 MessageReaction JSON 在缺少角色 ID 时仍反序列化为“我”的旧回应，不需要新增 Room 迁移。新增独立单元测试约束此行为。

## 边界与未实现的项目
- AI 角色是否选择贴表情由当次模型输出决定，并不是每条群聊消息都会自动贴表情。
- 目前只能撤销我自己的回应；不允许替其他角色随意撤销。
- 最近使用属于本机 UI 偏好，不代表已纳入聊天完整备份。
- CI 自动测试与构建不等于签名正式安装包或真实手机验证。
