# 怀民亦未寝（Cleos 增量定制）

这是 `codex-knowledge` 中完全隔离的 Android 定制应用目录，不属于知识库的 `projects/` 条目，不参与知识条目计数，也不会修改其他项目。

## 目标

- 保留 Cleos 当前基线版本的全部原有功能。
- 手机安装后显示名称：**怀民亦未寝**。
- 使用独立 Android applicationId：`com.lin.huaimin`，可与原版 Cleos 共存。
- 保留原有 `set_alarm` / `set_timer`。
- 新增 `get_next_alarm`：读取 Android 系统公开的“下一次闹钟”时间。
- 新增 `show_alarms`：直接打开手机系统时钟的闹钟列表。
- AI 被明确告知 Android 普通应用不能读取系统时钟中的完整闹钟明细，因此不能编造全部闹钟列表。

## 基线

上游：`jqzhang921-sudo/cleos`

固定提交：`c19e50bcc0f75b09e0b54dff8f45a2e74163eb37`（Cleos 0.35.3）

为了保持上游功能完整且避免把一个未声明项目级 LICENSE 的仓库整份重新发布到这里，本目录采用“固定上游提交 + 最小增量补丁”的方式。GitHub Actions 构建时会拉取该固定提交，再应用 `apply_huaimin.py`。

## 构建

当前定制版本：**0.36.8**（versionCode 62015）。

双击聊天消息旁的 TA 或自己的头像，可留下「拍一拍」提示、头像摇动和可选震动；4 秒内连续拍同一方会合并计数。普通拍动随下一条实际消息告知模型；连续拍 TA 达到 10 下后，停手约 4.5 秒可获得简短回复。连续拍自己仍等下一条实际消息，关闭「拍回来」会阻止等待中的连拍回复。

「设置 → 能做的事 → 拍回来」控制模型的 pat_user 工具和连拍回复；支持工具调用的模型可在回复之间拍你一下。「设置 → 聊天 → 拍一拍」和长按 TA 的消息头像可修改动作、名字后缀和震动设置。

保留 0.36.7 的 36 个内置表情以及 ❤️「我的」自定义表情入口。用户发送表情包时，将表情名称对应的实际图片接入普通图片的编码和多模态请求路径，支持看图的模型可读取画面及图中文字。聊天显示方式及原有表情标记不变，已有表情和改名前的名称可以直接解析，无需重新添加；该能力与「TA 发表情包」开关无关。普通图片和表情图片共用最近四张图片的预算；不能接收图片的模型仍保留文字回退。动态表情经现有图片编码器按静帧传入。

保留 0.36.3 的「保存」按钮，最小尺寸 72 × 48 dp，空间不足时自动换行。保存当前 TA 的聊天、电话和语音模型及待保存的 Key，等待写入并回读确认后返回；保存失败时显示原因并留在当前页。自动保存与显式保存按顺序执行，避免旧写入覆盖已确认的选择。

模型页面保留「随想」，接口地址为 `https://www.sui-xiang.net/v1`；填写该服务的 API Key 后，用“测试并列出模型”读取列表，再选择实际可用模型。

保留全部五张预设壁纸，包括「海底峡谷」；「月下庭园」仍为首次安装及“用回默认”的默认壁纸。保留已修复的应用图标。

壁纸在源码资源中加入，再经 Gradle 正常构建 APK，不修改编译后的安装包资源。

工作流：`.github/workflows/huaimin-yiweiqin-android.yml`

每次本目录或工作流发生变化，会自动：
1. 拉取固定版本 Cleos；
2. 应用“怀民亦未寝”增量修改；
3. 运行 Android 单元测试；
4. 构建 Debug APK；
5. 上传名为 `怀民亦未寝-debug-apk` 的 Actions Artifact。

构建前会实际解码图标，构建后会反向解析 APK 的 `icon`、`roundIcon` 和桌面启动入口，并确认包内图片与原图字节一致、可完整解码且 APK 签名有效。损坏图片不能再通过构建并被上传。

交付文件为可直接安装的「怀民亦未寝-0.36.8.apk」。GitHub Actions Artifact 用于归档构建产物。
