## 安全覆盖安装流程
1. 从原 App **先导出完整备份**并离线保存，特别注意密钥与私密会话。
2. 只使用 **经上述原正式版证书签名** 且校验通过的 Release APK；GitHub CI 的 Debug APK 和未签名 Release APK 不能覆盖原正式包。
3. 保留旧 App，直接安装同包名、同证书且更高 versionCode 的 62047 APK；**不要先卸载**、不要清除 App 数据。
4. 升级后检查：角色和单聊/群聊历史、群成员、模型配置与 API Key、自定义字体/表情、媒体文件及备份功能。
5. 如果系统提示「与现有安装包冲突」或「不能安装」，停止操作，不卸载旧 App。排查原安装来源和签名，勿尝试改变密钥来绕过限制。
6. 保留独立加密备份和此前可用的正式版 APK，以便分析故障；不保证不同签名（例如 Debug）的旧包原地覆盖。
