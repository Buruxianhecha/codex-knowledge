# 问薪无愧 · v0.1.2-beta

安卓记账 APP：支持账户、计划、首页预算、报表及设置。桌面图标改为暖米白背景、珊瑚橙钱包。

## APK 固定签名

从 v0.1.2 Beta 起发布版使用稳定发布证书，不再每次临时生成 Debug 签名。签名校验指纹和配置见 `android/SIGNING.md`。首次从 v0.1.0/0.1.1 迁移，由于旧 Debug 证书不同，需要先导出账本备份再安装；之后相同包名及签名可覆盖升级。

**私钥不在公开仓库。** GitHub Actions 需一次性配置 `WENXIN_KEYSTORE_BASE64` 与 `WENXIN_SIGNING_PASSWORD`。未配置时构建明确失败，不会输出不安全的临时签名 APK。

当前为测试版，真实手机安装测试和部分智能服务仍待完善。
