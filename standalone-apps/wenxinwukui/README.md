# 问薪无愧 · v0.1.1-beta

移动端优先的记账与计划应用：暖金首页、账户净资产、今日/近7天/近30天/今年待办计划、收支趋势与分类报表、“我的”设置，以及本地账单管理。

## 可用功能

- 每笔账单可输入金额、收支类别、日期、备注、关联账户、商家和成员。
- 月度预算、月历及财务趋势根据真实账单计算。
- 资产账户初始余额自行录入，截图金额未预置；关联账单影响账户实时余额。
- 计划按截止日期统计，支持新增、修改、完成与删除。
- 本地浏览器存储与 JSON 覆盖恢复 / 备份导出。
- 智能速记仅为关键词解析，不是云端AI。

## 安卓安装版

独立 Android WebView 工程位于 `android/`。以独立包名 `com.wenxinwukui.ledger` 构建，APK内离线包含前端；文件导入导出通过 Android 系统文件选择器。没有银行/微信/智能客服/通知/真正手势锁集成；相关入口仅供体验。

浏览器 PWA 与 APK 的本地存储彼此独立，卸载应用将丢失该应用保存的记录。建议定期导出备份。Debug APK 的签名仅供测试，不能保证今后跨构建覆盖安装。
