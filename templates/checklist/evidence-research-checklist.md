# 深度写作与证据研究清单

## 1. 范围

- [ ] 研究问题、对象、时间范围和资料截止日明确。
- [ ] 区分事实核验、机制解释、规范评价和建议。
- [ ] 明确不会回答或当前无法回答的问题。

## 2. 材料账本

- [ ] 每个核心材料有稳定 ID。
- [ ] 记录发布主体、日期、获取日期和原始位置。
- [ ] 视频有时间码，文档有页码/段落。
- [ ] 本地材料记录 SHA-256。
- [ ] 标记原始、转述、切片、评论和二创。

## 3. 来源层级

- [ ] 优先本人、官方、法规、仓库和原始记录。
- [ ] 二次报道回溯原始来源。
- [ ] 多来源是否真正独立，而非互相转载。
- [ ] 自述只证明“主体这样说”，不自动证明外部事实。

## 4. 命题表

- [ ] 每个关键命题可独立判断真伪。
- [ ] 绑定最强支持证据和定位。
- [ ] 记录反证、冲突和空白。
- [ ] 写明允许措辞和禁止升级的措辞。
- [ ] `参与/负责/主导`、`相关/导致` 等动词有证据门槛。

## 5. 数字与时间

- [ ] 单位、币种、时区和样本口径明确。
- [ ] 实时、盘中、收盘、结算和修订分开。
- [ ] 预测、实际和事后标注分成不同系列。
- [ ] 单点快照不外推长期趋势。

## 6. 多智能体

- [ ] 按证据职责分工，不按章节自由写作。
- [ ] 共用材料 ID 和命题 Schema。
- [ ] Agent 摘要不作为原始证据。
- [ ] 冲突进入统一裁决。
- [ ] 最终有独立引用审计。

## 7. 写作

- [ ] 事实、分析和建议在结构上可区分。
- [ ] 不确定性和限制进入正文。
- [ ] 没有证据时写“未确认”，不补全。
- [ ] 引用紧邻支持的命题。
- [ ] 结论不超出样本、时间和来源范围。

## 8. 隐私与交付

- [ ] 署名按用户当次要求，不沿用旧稿。
- [ ] 检查文件名、正文、页眉页脚和致谢。
- [ ] 检查 Word/PDF author、lastModifiedBy 等元数据。
- [ ] 清理批注、修订、隐藏文本和不应公开的账号信息。
- [ ] Word/PDF 均完成渲染和页面检查。
