# Checklist：参考模板 / 现有项目保护式修改

## 修改前

- [ ] 明确这是新建还是修改现有作品。
- [ ] 列出 Must change。
- [ ] 列出 Must preserve。
- [ ] 列出允许的最小 May adapt。
- [ ] 坐标、尺寸、文字、数量等显式标注已抄入验收表。
- [ ] 参考图片的用途已确认：视觉方向、结构参考，还是实际素材。

## 修改中

- [ ] 不重排未要求变化的版式。
- [ ] 不替换未要求变化的品牌/模板元素。
- [ ] 不用“美化”覆盖明确坐标。
- [ ] 修改现有网站时保留已有路由、数据和业务行为，除非需求要求改变。
- [ ] 不把视觉参考图直接嵌入成网页素材，除非明确要求。

## 修改后

- [ ] 指定对象已按要求改变。
- [ ] 未指定对象做 diff 后保持不变。
- [ ] 模板整体比例、边距和层级没有意外变化。
- [ ] 桌面/手机或目标尺寸均复核。
- [ ] 可以逐条解释所有变化，没有“顺手改了”的额外差异。
