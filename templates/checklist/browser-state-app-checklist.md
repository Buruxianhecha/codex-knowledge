# 浏览器持久状态应用清单

## 数据模型

- [ ] 有 `schemaVersion`。
- [ ] 每条业务数据有 `ownerId` / `runId`。
- [ ] 有稳定主键、创建时间、更新时间和修订号。
- [ ] 随机结果或随机种子已持久化。
- [ ] 完成、死亡、删除、回收站等状态有明确字段。

## 迁移

- [ ] 有效新版本优先。
- [ ] 新版本损坏时仍尝试旧版本。
- [ ] 迁移幂等，可重复运行。
- [ ] 迁移失败保留原始数据，不静默清空。
- [ ] 旧用户身份有明确映射。

## 并发与事务

- [ ] 动作携带场景/对象版本。
- [ ] 重复动作是 no-op。
- [ ] 旧标签页不能覆盖新快照。
- [ ] 持久化在 UI 确认前同步完成或具备可靠事务。
- [ ] 显式加载其他档案时有激活语义。

## 多账户

- [ ] 至少两个测试账户。
- [ ] 账户 A 无法读写账户 B 数据。
- [ ] 退出与切换后缓存不串号。
- [ ] 本地隔离不被宣传为服务端授权。

## 恢复

- [ ] 刷新后状态保持。
- [ ] 浏览器重启后状态保持。
- [ ] 导出 -> 清空测试环境 -> 导入恢复已演练。
- [ ] 损坏数据有错误提示和回退。
- [ ] 完成/死亡/删除状态不会复活。

## 容量与文件

- [ ] 1/5/20/50 项批量路径。
- [ ] 大文件、异常格式和容量耗尽。
- [ ] 写入中断、重试和部分成功。
- [ ] Blob 与元数据的孤儿清理。
- [ ] 性能样本覆盖目标规模。

## 真实浏览器

- [ ] 桌面、移动、窄屏和真机触摸。
- [ ] 文件选择器、权限、离线和可见性切换。
- [ ] 隐私窗口边界已说明。
- [ ] 用户知道清理站点数据的后果。
