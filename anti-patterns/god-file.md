# God File（上帝文件）

## 症状
单个文件包含多种不相关职责，超过 300 行且持续增长。

## 腐烂路径
```
"就加一个路由" → 文件涨到 200 行
"再加一个功能" → 300 行
"再加一个诊断接口" → 400 行
→ 无人敢重构，因为所有东西都耦合在一起
```

## 检测信号
- 单文件超过 300 行
- 同一个文件里看到：路由 + 业务逻辑 + 配置 + 验证 + 调试
- import 列表超过 20 行

## 修复
按职责拆分：routes/ services/ models/ config/ — 每个文件单一职责。

## 已知案例
- pdf-to-excel: main.py 410 行，含 6 种职责
