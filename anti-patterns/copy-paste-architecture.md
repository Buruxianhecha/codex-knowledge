# Copy-Paste Architecture（复制粘贴架构）

## 症状
同一个接口/流程在多个文件中各自实现，代码 70% 重复。改一处需要改所有副本。

## 腐烂路径
```
第1次: 快速实现, 没问题
第2次: 复制粘贴, 代码量×2
第3次: 再复制, 代码量×3 → 行为开始不一致
第N次: 某个副本的 bug 被修复但其他副本没修 → 用户看到不一致行为
```

## 检测信号
- 三个以上文件包含相同结构的类/函数
- 同样的常量在多处定义
- "先复制一个再改"是口头禅

## 修复
在第二个实现出现时就抽公共接口/基类。如果已经 N 个副本，先写测试锁定现有行为，再逐步统一。

## 已知案例
- pdf-to-excel: ocr.py / ocr_paddle.py / ocr_gpt.py 各自定义 FakeTable
