# 百度网盘备份

## 适用场景

- 本地 Windows 文件或文件夹备份到百度网盘
- 需要保留源文件，不做移动删除
- 需要以云端列表验证结果，而不是只看本地 UI

## 复用原则

1. 先确认本地源路径真实存在，统计文件数量和总大小。
2. 先确定云端目标目录，再执行上传。
3. 优先用脚本和 API，不先依赖 UI 自动化。
4. 上传后必须核对云端文件名、大小、缺失项和额外项。
5. 只有云端验证通过，才算真正完成。

## 默认约定

- 默认使用 `*.docx` 作为小说备份范围，除非用户明确要求全部文件
- 默认保留本地目录层级
- 默认不打印任何 cookie、token、BDUSS、STOKEN、bdstoken
- 默认不修改或删除源文件

## 输出要点

- 本地源路径
- 云端目标路径
- 上传数量
- 跳过数量
- 总字节数
- 缺失文件
- 多余文件
- 大小不匹配文件
