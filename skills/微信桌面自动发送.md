# 微信桌面自动发送

## 适用场景

- Windows 桌面微信
- 已登录会话
- 给明确联系人发送已知内容
- 发送文本或图片

## 复用原则

1. 先确认联系人，避免发错聊天对象。
2. 优先用 UI Automation 定位输入框和发送按钮，不先猜坐标。
3. 输入前先确认消息内容，再写入输入框。
4. 发送图片前先把图片准备好，确认预览出现。
5. 点击当前可见发送按钮的真实中心位置，不依赖过时坐标。
6. 发送后用聊天记录确认结果。

## 默认约定

- 不在输入框为空时直接点发送
- 不把敏感信息直接截进图里
- 如果按钮看起来正常但没发出去，先重新读取按钮状态

## 输出要点

- 目标联系人
- 发送内容
- 发送类型：文本 / 图片
- 是否在聊天记录里看到结果
- 如果失败，失败在定位、输入、粘贴还是发送
